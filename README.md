# IVR Voice Studio

Create neural text-to-speech prompts and convert recordings into dialer-ready audio.

## Start on Windows

Double-click `start.bat`, or run it from Command Prompt. The first run installs the Python packages and bundled FFmpeg executable. Then open <http://localhost:5000>.

Internet access is required while generating Edge neural speech. Audio conversion works locally after installation.

The common dialer setting is **WAV, 8 kHz, mono, 16-bit PCM**. Some systems require **8 kHz μ-law**, which is also available.
